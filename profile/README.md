## How I Tend to Work

- Figure out who's going to get paged before deciding what to automate.
- Treat observability, permissions, failure handling, and recovery as part of the architecture rather than cleanup work.
- Separate AI reasoning from operational authority; recommendations can be automated more aggressively than state-changing actions.
- Write the runbook and failure cases alongside the implementation, not after.
- Keep reference implementations small enough that another engineer can review the whole thing.
- Be explicit about tradeoffs and what I would improve next.
